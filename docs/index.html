ipkit

Agentic-first IP address & network utility service

Go No Database Plain Text API MCP Single Binary
View on GitHub Quick Start

Principles

Agent IS the Interface

No UI, no SDK. The API is the product. Every endpoint is designed for an AI agent to call.

Plain Text by Default

One labeled, grepable line per record. Token-cheap. JSON on demand via Accept header or ?format=json.

Instructive Errors

Every 4xx includes a hint telling the agent what to do next. Self-correct without a schema.

Self-Documenting

GET /help returns a one-page operating manual the agent loads at runtime.

Single Binary

Go, CGO_ENABLED=0, zero external dependencies. Deploys as one file.

Zero Config

Runs out of the box. Config layered: defaults < file < env < flags.

Quick Start

make build
./ipkit
# Listening on :7700

curl http://localhost:7700/ip/192.168.1.1
# ip=192.168.1.1 version=4 type=private private=true ...

curl http://localhost:7700/cidr/10.0.0.0/24
# cidr=10.0.0.0/24 network=10.0.0.0 broadcast=10.0.0.255 ...

curl "http://localhost:7700/contains?ip=10.0.0.5&cidr=10.0.0.0/24"
# ip=10.0.0.5 cidr=10.0.0.0/24 contains=true

curl "http://localhost:7700/subnet?cidr=192.168.1.0/24&prefix=26"
# 192.168.1.0/26
# 192.168.1.64/26
# 192.168.1.128/26
# 192.168.1.192/26
